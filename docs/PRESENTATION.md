### 第 8 页 — 市场状态判断（Regime）

```
标题：市场状态判断 — 熊市自动降仓

  四维评分模型（每天更新）：

  趋势(25%)  +  波动率(25%)  +  估值(25%)  +  市场宽度(25%)
     ↓              ↓              ↓              ↓
  大盘 vs     20日年化波    全市场PE/PB    上涨家数占比
  200日均线    动率分位值     历史分位     涨停温度

          综合评分 → 建议仓位比例

  2025-01  震荡偏多 → 65%  仓位
  2025-10  牛市高波动 → 85% 仓位
  2025-11  牛市高波动 → 85% 仓位
  2026-01  牛市高波动 → 65% 仓位（系统觉察风险，主动降仓）

  效果：避免"千股跌停跑不掉"——行情恶化时已有现金缓冲

### 第 9 页 — 实盘模式架构

```
标题：实盘模式 — 9 个微服务全自动运行

  ┌─────────────────────────────────────────────────────┐
  │  06:00   data_collector 拉取隔夜海外/公告数据        │
  │  08:00   premarket_service 盘前推荐（NLP+模型）      │
  │  09:25   竞价修正 → 最终推荐清单                      │

  │  15:00   日终结算 + 数据质量检查 + 日报生成           │

    策略 → Redpanda → order_manager → risk_engine(10ms)

### 第 10 页 — 风控体系

```
标题：三层风控 = 事前 + 事中 + 极端预案

  ★ 事前风控（下单前 <10ms）
    ├ 单票 ≤20%  ·  行业 ≤40%
    ├ 日申报 <20,000 笔  ·  秒申报 <300 笔（合规硬限）
    ├ ST/停牌/黑名单过滤
    └ 可用资金 + 成本检查

  ★ 组合级风控（实时）
    ├ 回撤熔断：当日 >15% 或 5日 >25% → 强制减仓
    ├ 波动率目标：当前波动率 > 目标 → 自动降仓
    └ VaR/CVaR 历史模拟法

  ★ 极端行情预案
    ├ 千股跌停 → 优先减可成交的 → 无法离场 → 股指期货对冲
    ├ 预设紧急现金缓冲
    └ 保留人工干预通道
```

**配图**：三层同心圆示意图，越外层越紧急。

### 第 12 页 — 数据与合规

```
标题：数据可审计 + 程序化交易合规

  数据审计：
  · 每条信号记录 feature_snapshot（当时的全部因子值）
  · 每笔订单记录 signal_id → order_id → fill 完整链路
  · audit/app/error/perf 四类日志分层存储
  · 所有日志不可删除、不可修改

  程序化交易合规（2025 年 7 月起新规）：
  · 系统内置报告信息管理 ← 向券商报告的材料
  · 秒申报 ≤ 300 笔硬限制 ← 高频交易认定标准
  · 撤单率 ≤ 70% 实时监控 ← 四类异常行为防控
  · 全日申报 ≤ 20000 笔自动降频

  数据安全：
  · 数据库访问通过 ClickHouseClient / MySQLClient 统一入口
  · 配置文件通过 .env 分离（.gitignore 排除密钥）
  · 交易 API 仅 order_manager 有权调用（边界隔离）
```
